## 9. DOCUMENT FORMATTING REQUIREMENTS

### File Naming Convention

```
EVIDENCE_[Number]_[DocumentType]_[Date].pdf
```

Example: `EVIDENCE_01_MSc_Certificate_20231201.pdf`

### File Specifications

| Requirement | Specification |
|-------------|---------------|
| Format | PDF (preferred), PNG/JPG for images |
| Maximum Size | 5MB per file |
| Resolution | 300 DPI minimum for scans |
| Colour | Full colour preferred |
| OCR | Searchable text where possible |

### Document Quality

- All documents must be legible
- Translations required for non-English documents (by certified translator)
- Notarisation required where specified
- Original documents available upon request
