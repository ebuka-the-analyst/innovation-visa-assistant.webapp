Develop a Comprehensive Preschool Website with CRM and Content Management
Posted 1 hour ago
Worldwide

Summary
We are seeking a skilled web developer to create an end-to-end preschool website that integrates a CRM and a workflow management system for educational content tailored for teachers. The ideal candidate will ensure a user-friendly interface and robust functionality to manage student data, lesson plans, and communication.

The platform will be built using React, TypeScript, and Next.js, with Supabase used for backend services including database management, authentication, and real-time features.

Key Responsibilities:

Develop a complete preschool website with integrated CRM and workflow management system

Build responsive and user-friendly interfaces using React and Next.js

Implement scalable and maintainable code using TypeScript

Integrate Supabase for database, authentication, and backend functionality

Create systems to manage student data, lesson plans, teacher workflows, and communication

Ensure performance, security, and reliability of the platform

Requirements:

Strong experience with React, TypeScript, and Next.js

Experience working with Supabase or similar backend platforms

Experience building CRM systems or admin dashboards

Understanding of database design and API integration

Ability to build clean, scalable, and maintainable code

Preferred:

Experience with education platforms or school management systems

Knowledge of workflow automation tools or CMS development

If you are passionate about enhancing educational experiences through technology, we would love to hear from you.
