# ✅ WHAT HE SAID THAT IS 100% TRUE

### ✅ 1) `visibility: hidden` IS A PROBLEM

YEP. SVG DOESN’T ALWAYS “PAINT” WHEN IT’S HIDDEN → YOU GET BLANK PNG.

✅ USE `opacity: 0` INSTEAD.

---

### ✅ 2) YOU MUST DISABLE ANIMATIONS ON EXPORT CHARTS

YEP. ANIMATIONS MAKE CAPTURE TIMING UNSTABLE.

✅ ADD `isAnimationActive={false}` + `animationDuration={0}` FOR EXPORT-ONLY CHARTS.

---

### ✅ 3) YOU MUST WAIT UNTIL SVG IS READY

YEP. IF YOU CAPTURE EARLY, YOU’LL CAPTURE EMPTY OR HALF-PAINTED CHART.

✅ CHECK:

* SVG EXISTS
* `getBBox()` HAS VALID WIDTH/HEIGHT
* ENOUGH ELEMENTS INSIDE SVG

---

### ✅ 4) VALIDATE PNG BEFORE EMBEDDING

YEP. DON’T “ASSUME” CAPTURE WORKED.

✅ CHECK:

* STARTS WITH `data:image/png;base64,`
* LENGTH > 5000 (OR SIMILAR)

---

### ✅ 5) jsPDF CAN FAIL IF IMAGE ISN’T DECODED YET

YEP. `await img.decode()` MAKES THIS CLEAN.
